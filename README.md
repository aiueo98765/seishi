# SEISHI — 着床までの旅

精子になって、膣内から子宮内膜までひたすら泳ぎ続ける3人称トンネルランナー。
障害物をよけながら卵子に辿り着き、受精して、胚として子宮内膜へ着床するまで。

**遊ぶ → https://aiueo98765.github.io/seishi/**

`index.html` 1枚で完結。外部ライブラリもアセットも0個（音も全部その場で合成）。

## 操作

| | |
|---|---|
| `←→↑↓` / `WASD` | 泳ぐ向きを変える |
| `SPACE` 長押し | 全力スイム。速いがスタミナを食い、切らすとしばらくバテる |
| スワイプ / DASH | スマホ |
| `P` `ESC` / `M` | 一時停止 / 音 |

拾うもの：**果糖**（スタミナ＋体力）、**追い潮のリング**（加速）。
当たると痛いもの：**白血球**（最大）、**粘液の塊**、**酸の泡**、**壁**、**ライバル精子**。

## コース（全6区間・2〜3分）

| 区間 | 性格 |
|---|---|
| 膣内 | 酸の泡。細い |
| 子宮頸管 | 粘液の塊だらけ。狭くてよく曲がる |
| 子宮腔 | 広いが白血球が寄ってくる |
| 卵管 | 繊毛の流れで横に押される |
| **受精** | 卵子に到達。連打で透明帯をこじ開ける。ライバルゲージか制限時間に負けたら終わり |
| 子宮内膜 | 胚になって分裂しながら進み、光る内膜に飛び込む。外すと3回まで押し戻される |

クリアは**タイムと着床位置の正確さ**で S〜C。

## 決めごと

- **カメラは真後ろ固定、回転は一切しない。** 3人称だがマウスルックの類は足さない（本人の指定）。
- **Three.js は使わない。** Canvas2D の自前透視投影。`tube(z)` が管の芯と半径を返し、
  `drawTube()` がリング×セグメントの四角形を奥→手前に塗るだけ。
- **音はファイル0個。** WebAudio のオシレータとノイズバッファで心音・スイム音・被弾音を合成。
- 距離の表示は実際の旅になぞらえて 0〜20cm。右上の「残りライバル」は3億から減る飾り。

## 踏んだ罠

1. **減衰は必ず `Math.pow(k, dt)`。**
   プレビュー環境で rAF が 360fps 出た。壁ズリの `p.spd *= 0.90` のようなフレーム単位の
   係数があると、高fps機では毎秒 0.9^360 が掛かって前に進まなくなる。
2. **カメラを自機の x,y にそのまま置くと壁を突き抜ける。**
   管が細い区間（子宮頸管・卵管）で壁際に寄ると、手前のリングが画面を覆いきれず背景が見える。
   カメラは `lerp(管の芯, 自機, 0.55)` で芯寄りに置く。曲がり幅も管の半径に比例させた。
3. **尾は頭より手前にある。**
   頭が一番奥なので、頭を先に描いてから尾を重ねる。逆にすると尾が頭の裏に隠れて
   ただの白い玉になる。
4. 壁ズリのダメージは連続で入る。クールダウンと法線速度のしきい値を付けないと
   壁際で旋回しただけで溶ける。

## 中身の地図

`index.html` 1ファイル。上から CSS → HUD/画面の DOM → スクリプト。

- `ALL[]` … ステージ定義（長さ・半径・曲がり・色・出現密度）
- `tube(z)` / `paramsAt(z)` … 管の形。区間の境目は色も半径も補間する
- `drawTube()` `drawSperm()` `drawEgg()` `drawEndWall()` … 描画
- `update(dt)` … 入力・速度・壁・衝突・受精QTE・着床判定
- `window.__seishi.jump(z) / heal() / info()` … 動作確認用。
  z は 0〜3140、卵子は 2400、着床の壁は 3140。
