# 精子 — 着床までの旅

精子になって、膣内から子宮内膜までひたすら泳ぎ続ける3人称トンネルランナー。
障害物をよけながら卵子に辿り着き、受精して、胚として子宮内膜へ着床するまで。

**遊ぶ → https://aiueo98765.github.io/seishi/**

| ファイル | なに |
| --- | --- |
| `index.html` | 本体。ゲームぜんぶ |
| `hige.js` | 「着床」などに使う字の輪郭（フォント本体ではない） |
| `vendor/trystero.js` | 1v1 対戦の通信。対戦を開いた時だけ読み込む |

音はファイル0個で全部その場で合成。CDN は Google Fonts の予備が一つだけで、落ちても遊べる。

## 操作

| | |
|---|---|
| `←→↑↓` / `WASD` | 泳ぐ向きを変える |
| `SPACE` 長押し | 全力スイム。速いがスタミナを食い、切らすと28まで戻るまで使えない |
| スワイプ / DASH | スマホ |
| `P` `ESC` / `M` | 一時停止 / 音 |

拾うもの：**果糖**（スタミナ＋体力）、**追い潮のリング**（加速）。
当たると痛いもの：**白血球**（最大）、**粘液の塊**、**酸の泡**、**壁**、**ライバル精子**。
ごくまれに**顔つきの白血球**が湧く。これだけは痛くない代わりに、
さわると**4秒のあいだ鈍足**（目標速度が半分）になる。画面の下に残り秒数が出る。

## コース（全6区間・2〜3分）

| 区間 | 性格 |
|---|---|
| 膣内 | 酸の泡。細い |
| 子宮頸管 | 粘液の塊だらけ。狭くてよく曲がる |
| 子宮腔 | 広いが白血球が寄ってくる |
| 卵管 | 繊毛の流れで横に押される |
| **受精** | 卵子に到達。連打で透明帯をこじ開ける。ライバルゲージか制限時間に負けたら終わり |
| 子宮内膜 | 胚になって分裂しながら進み、光る内膜に飛び込む。外すと3回まで押し戻される |
| **裏の管** | 隠し。内膜の横の**小さな緑の円**に入ると現れる。緑と黒の細い管を760進む |

### ランク（クリア評価）

**着床位置の正確さだけ**で決まる。タイムが効くのは SSS の条件に入っている時だけ。
`acc` は光る場所の中心からのズレを判定円の半径で割った値で、0がど真ん中、1がふち。

| | 条件 |
|---|---|
| **SSS** | `acc<0.3` かつ 残り体力 60超 かつ **2分4秒（124秒）以内** |
| **S** | `acc<0.3` かつ 残り体力 60超 |
| **A** | `acc<0.5` |
| **B** | `acc<0.8` |
| **C** | それ以外（`acc>1` は弾かれて3回で終わり） |

### 裏の管（隠しステージ）

- 最後の壁には、光る内膜とは**別に小さな緑の円**がある（`GATE_A` / `GATE_RR` / `GATE_HIT`）。
  着床判定より**先に**緑の円を見て、入っていたら `enterSecret()` で裏へ飛ぶ。
- 裏に入ると `SECRET_ON=true` になり、**区間表の最後の1つ（裏の管）が使えるようになる**。
  入るまでは `lastIdx()` が最後の1つを隠すので、地図にも色の補間にも出てこない。
  終点も `endZ()` が `IMPLANT_Z`（3140）か `SECRET_Z`（3900）を返し分ける。
- 抜けると**隠しの進捗「裏側」と隠しスキン「翠」**が開く。

## きせかえと進捗

- **スキン20種**。頭の色・尾の色・装飾の組で、ゲーム中もきせかえ画面のプレビューも
  `paintHead()` / `paintAcc()` の同じ関数で描く。装飾は王冠・猫耳・角・ハチマキ・
  ゴーグル・眼鏡・鼻・輪・炎・星・帽子・葉・渦・盾・殻・顔・一筋・的・月桂冠。
- **進捗20種**。達成するとマイクラ風のトーストが右上に出て、対応するスキンが解放される。
  一度に出すのは3つまでで、あふれた分は順番待ちにする。
- **進捗の画面は 4列×5行 の盤で、スクロールさせない**（本人の指定）。
  20個ちょうどで埋まるようにしてあるので、**増やすなら4の倍数**で。
  375px 幅でも収まるよう、字は `clamp()` で縮む。
- **隠しの進捗とスキン（`hide:true`）は、取るまで一覧に出さない。**
  灰色の枠や「？？？」すら出さない（本人の指定）。盤を4×5のまま保つため、
  隠し進捗は盤ではなく `#achHidden` に別で並べる。
  数えるのも表に出る20個だけで、隠しは「＋ 隠し 1」と後ろに付ける。

## 位（タイトル画面）

ためた果糖でプレイヤーの位が上がる。**果糖5000個でマスター**（最高位）。

- 1回の旅が終わるたび `bankRun()` が **その旅で拾った果糖＋クリアのランクぶん**を足す。
  ランクぶんは **SSS +250 / S +100 / A +40 / B・C なし**（S と A は本人の指定、
  SSS はそれに合わせて決めた）。力尽きても対戦でも、拾った果糖は入る。
- 段は**シルバー・ゴールド・プラチナ・ダイヤ・マスターの5つ**（`RANKS`）。
  境目は 0 / 600 / 1600 / 3000 / 5000。
- **段ごとに絵がつく**（`rankSVG()`）。シルバー・ゴールド・プラチナは六角の宝石、
  ダイヤは菱形、マスターは王冠。色は段の3色のグラデーションで、画像ファイルは使わない。
  同じ絵を2か所に出すので、グラデーションの id が重ならないよう呼ぶ側で札を付ける。
- **段の一覧は出さない**（本人の指定）。タイトルに出るのは**今の位の絵と名前、ためた果糖だけ**で、
  次が何でいくつ必要かは見せない。
- 進捗・選択中のスキン・ベストタイムは `localStorage` の `seishi_save` に入る。

## 1v1 オンライン対戦

どちらが先に着床できるかを競う。サーバーは持たない。

- タイトルの「1v1 で競う」から、**部屋をつくる**と4文字の合言葉が出る。
  相手がそれを入れて**入る**と、3カウントのあと同時にスタート。
- 相手さがしだけ公開の nostr リレーを使い、つながったあとは **WebRTC で直接**やりとりする。
  送るのは位置・尾の角度・体力・卵膜の掘り具合だけで、12回/秒。
- **障害物は両者まったく同じ配置になる。** 合言葉から種を作り、湧かす所だけ
  種つきの乱数（`RNG`）に差し替えている。見た目だけの塵や粒は普通の乱数のまま。
- 相手は青く光る**ゴースト**として管の中に見える。上のバーにも相手の現在地が出て、
  画面上部に「リード +2.3cm」「ビハインド -1.1cm」が出る。
- 卵子の連打勝負では、「ライバルの進捗」バーが**相手の実際の掘り具合**になる。
  ただし対戦中は相手に先を越されても終わらない（負けるのは制限時間切れだけ）。
- 先に着床したほうが勝ち。相手が力尽きたらその時点で勝ち。通信が切れたら引分。
- 結果画面の「もう一度やる」は**両方が押すと**新しい種で再戦する。

## 決めごと

- **カメラは真後ろ固定、回転は一切しない。** 3人称だがマウスルックの類は足さない（本人の指定）。
- **Three.js は使わない。** Canvas2D の自前透視投影。`tube(z)` が管の芯と半径を返し、
  `drawTube()` がリング×セグメントの四角形を奥→手前に塗るだけ。
- **上の場所バーは地図のほうが動く。** 現在地は画面中央に固定し、区間と目盛りを
  `translateX` で流す。全体の進み具合は、通った分が光ることで分かる。
- **音はファイル0個。** WebAudio のオシレータとノイズバッファで心音・スイム音・被弾音を合成。
- 距離の表示は実際の旅になぞらえて 0〜20cm。右上の「残りライバル」は3億から減る飾り。
- **S/A/B/C のランクには大髭を使わない**（本人の指定）。
- **爽快感・迫力は遊びの数値に触れずに足す。** 速度線・残像・衝撃波・画角・
  被弾の一瞬止め（55ms）・区間名の叩き込み・「ギリギリ回避」の表示は、
  どれも見た目と音だけ。ダメージ量も速度も当たり判定も変えていない。
- **ダッシュ中の集中線はほどほどに**（本人の指定）。濃く長くしすぎると画面が埋まる。
  本数 `11+sv*9`、濃さ上限 0.28、長さ 0.11〜0.31 あたりが上限。
- **隠しは本当に隠す。** 裏の管も、その進捗もスキンも、取るまで気配を出さない。
  位の段も全貌を見せない（本人の指定）。

## 着床の演出と「大髭」

着床の瞬間だけ、白舟書体の**大髭**で「着床」を叩きつける。
このPCには `大髭113` がユーザー領域（`%LOCALAPPDATA%\Microsoft\Windows\Fonts`）に入っている。

- **フォント本体は配布しない。** 市販フォントなので同梱すると権利的にアウト。
  代わりに、使う字だけを**輪郭（パス）として抜き出して** `hige.js` に持たせてある。
  字形そのものは著作物ではないので、これは「フォントを配る」ことにはならない。
  おかげで**大髭が入っていない端末でも同じ字が出る**。
- 抜いたのは `着床成功受精勝利敗北引分子` の13字（47KB）。`fontTools` で TTF から
  SVG パスに変換したもの。字を増やしたい時は同じ手順で足す。
- タイトルロゴ「精子」も同じパスから作った SVG（色だけ桃色のグラデーションに変えている）。
- キャンバスでは `Path2D` に流して塗り、HTML の見出しは同じパスから組んだ `<svg>` を入れる。
  `hige.js` が読めなかった時だけ、CSS のフォント指定（大髭→Dela Gothic One）に落ちる。
- 演出は、吸い込み → 白閃光と衝撃波 → 光芒 → 背景を一段落として「着床」が縮んで止まる、の順。
- 「着床」の下に**虹色の一文**「気になるあの子を孕ませる！」を出す。
  虹は `time` でずれていく。ここだけ**大髭は使わない**：`孕` が大髭に無い恐れがあり、
  一字だけ別の書体に落ちると不揃いになる。確実に出るゴシック（`RAINF`）を 900 で太らせる。
  画面幅の 88% を超えたら字を縮めるので、スマホでも1行に収まる。

## 踏んだ罠

1. **減衰は必ず `Math.pow(k, dt)`。**
   プレビュー環境で rAF が 360fps 出た。壁ズリの `p.spd *= 0.90` のようなフレーム単位の
   係数があると、高fps機では毎秒 0.9^360 が掛かって前に進まなくなる。
2. **カメラを自機の x,y にそのまま置くと壁を突き抜ける。**
   管が細い区間（子宮頸管・卵管）で壁際に寄ると、手前のリングが画面を覆いきれず背景が見える。
   カメラは `lerp(管の芯, 自機, 0.55)` で芯寄りに置く。曲がり幅も管の半径に比例させた。
3. **尾は頭より手前にある。**
   頭が一番奥なので、頭を先に描いてから尾を重ねる。逆にすると尾が頭の裏に隠れて
   ただの白い玉になる。
4. **通り過ぎた物はカメラの直前で巨大化する。**
   自機より手前に来た障害物は投影が際限なく広がって画面を覆う。
   当たり判定を抜けた辺り（`dz` 5.4〜3.2）でフェードアウトさせる。
5. **入力が固まって動けなくなる。**
   ポインタを押したまま枠外で離すと `pointerup` を取りこぼし、古い座標で
   操舵し続けてキー入力が無視された。`pointermove` で `buttons===0` を見て解除し、
   `blur` と `visibilitychange` で全部離し、キーが押されている間はキーを優先する。
6. **`background-clip:text` の字は要素の箱からはみ出すと消える。**
   ランクに大髭を当てたら S が見えなくなった。字面が大きい書体を
   `line-height:1` の箱に入れると、はみ出した部分に背景が乗らない。
7. 壁ズリのダメージは連続で入る。クールダウンと法線速度のしきい値を付けないと
   壁際で旋回しただけで溶ける。
8. **裏に回ったタブは `requestAnimationFrame` が止まる。**
   絵を撮るときに「何秒後」を狙うと当たらない。`__seishi.step(dt,n)` で
   自分でコマを進めて `render()` まで呼ぶ。`__seishi.shot(t)` はその時点で固める。
9. **対戦で湧かす所に乱数を足すときは、必ず両者が同じ順番で引くこと。**
   顔つきの判定も `RNG()` を使うので、`if(RNG()<…)` の中に入れて
   「湧かす時だけ1回引く」形を両者で揃えている。
10. **裏の管は区間表に入れたまま隠す。** `ALL` に足してあるが `lastIdx()` が
   `SECRET_ON` を見て最後の1つを切る。切らないと `paramsAt()` の補間が
   内膜の終わり130手前から緑に寄っていき、入る前から裏の存在が見えてしまう。
11. **裏に入った直後の案内は上書きされる。** `enterSecret()` で `g.saidEnd=true` に
   しておかないと、`p.z>ALL[4].end` の「子宮内膜」の案内が同じコマで出て、
   「裏の管」の表示を消してしまう。裏の終わりの案内は `g.saidEnd2` で別に持つ。

## 中身の地図

`index.html` 1ファイル。上から CSS → HUD/画面の DOM → スクリプト。

- `ALL[]` … ステージ定義（長さ・半径・曲がり・色・出現密度）
- `SKINS[]` / `ACHS[]` … スキンと進捗の定義。`SV` がセーブ、`gotAch()` が達成処理
- `tube(z)` / `paramsAt(z)` … 管の形。区間の境目は色も半径も補間する
- `buildRibbon()` / `ribbon()` … 上の場所バー
- `drawTube()` `drawSperm()` `paintHead()` `drawEgg()` `drawEndWall()` … 描画
- `higeText()` / `higeSVG()` / `impactText()` … 大髭の字をパスから描く
- `startLanding()` / `drawLand()` … 着床のフィナーレ
- `NET` / `netOpen()` / `beginCountdown()` / `raceEnd()` … 1v1 対戦
- `mulberry32()` / `RNG` … 対戦で障害物を揃えるための種つき乱数
- `update(dt)` … 入力・速度・壁・衝突・受精QTE・着床判定
- `RANKS` / `RANK_BONUS` / `bankRun()` / `rankNow()` … 位
- `enterSecret()` / `SECRET_ON` / `lastIdx()` / `endZ()` … 裏の管
- `window.__seishi` … 動作確認用。z は 0〜3140（裏は 3900）、卵子は 2400。
  `jump(z)` 途中へ飛ぶ／`heal()`／`finale()` 終わりの壁の前へ／`gate()` 緑の円の前へ／
  `info()` 今の状態／`face(d)` 顔つき白血球を目の前に湧かす／
  `shot(t)` 着床の t 秒で固める（`release()` で解除）／
  `step(dt,n)` コマを進めて描く（裏タブで絵を撮るとき）。
